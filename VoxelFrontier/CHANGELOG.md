## [0.1.0] - Alpha Initial - [TBD]

- Godot 4.x project configuration
- Documentation framework
- Directory structure for assets, scenes, scripts, shaders, and data

### Core Systems
- Project bootstrapping
- Version tracking system
- Development status tracking

### Infrastructure
- Build scripts for Windows export

- Creative and Survival modes

## Version Numbering

- **Major.Minor.Patch**
- **Major:** Breaking changes or major feature releases
- **Minor:** New features, backward compatible
- **Patch:** Bug fixes and minor improvements

### Development Stages
- **0.x.x** - Alpha/Beta development
- **1.0.0** - First stable release
- **1.x.x** - Post-launch updates
